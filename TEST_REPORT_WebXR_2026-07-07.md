## Bugs Fixed

### 🐛 BUG-1: Camera Rotation Conflict in VR Mode
**Before:** `camera.rotation.y = yaw` and `camera.rotation.x = pitch` ran every frame, overriding VR headset tracking.
**After:** Camera rotation now only updates when NOT in VR:
```javascript
if (!renderer.xr.isPresenting) {
  camera.rotation.y = yaw;
  camera.rotation.x = pitch;
}
```
**Impact:** Mouse look works on desktop. Headset tracking works in VR. No conflict.

### 🐛 BUG-2: No Session End Handler
**Before:** No cleanup when user exits VR.
**After:** Added event listener:
```javascript
session.addEventListener("end", () => {
  send({ type: "update", data: { inVR: false } });
  logEvent("VR session ended");
});
```
**Impact:** Game state correctly updates when exiting VR.
