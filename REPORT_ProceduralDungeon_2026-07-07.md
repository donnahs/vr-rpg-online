## What Was Built

Replaced the static box dungeon with a **procedural room-based generator**:

| Feature | Before | After |
|---|---|---|
| Layout | Static square arena (40x40) | 5-8 connected rooms with corridors |
| Rooms | 1 open space | 5-8 procedurally placed rooms (3-6 cells each) |
| Corridors | None | L-shaped corridors connecting every room |
| Walls | Random scattered blocks | Proper walls surrounding rooms + corridors |
| Spawn points | Hardcoded (5 fixed) | Room centers (dynamic) |
| Enemy/item placement | Random in arena | Only on valid floor tiles |
| Determinism | Partial | Fully seeded (same seed = same dungeon) |

---

## Algorithm

1. **Grid setup:** 30x30 cell grid (0=void, 1=floor, 2=wall)
2. **Place rooms:** Random sized (3-6 cells), non-overlapping, 200 placement attempts
3. **Connect corridors:** L-shaped corridors between sequential rooms
4. **Mark walls:** Any void cell adjacent to floor becomes a wall
5. **Convert to AABB:** Wall cells → Three.js collision boxes
6. **Spawn entities:** Enemies and items placed only on floor cells
